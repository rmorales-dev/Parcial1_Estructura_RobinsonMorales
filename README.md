Ejercicio 14 – Carrera universitaria
Una universidad tiene registrados los resultados de una competencia deportiva.
De cada participante se conoce su nombre, número de participante y tiempo obtenido.
Los organizadores necesitan presentar los resultados comenzando por el participante con el mejor tiempo y terminando con el de mayor tiempo.
Desarrolle una solución que permita organizar los resultados.
